# Arocena — Private Family Office

Static website for Arocena Private Family Office, Punta del Este, Uruguay.

## Deploy to Vercel (30 seconds)

### Option A — Vercel CLI
```bash
npx vercel
```
Follow the prompts → live URL instantly.

### Option B — Drag & drop
Go to [vercel.com/new](https://vercel.com/new) → drag this folder → done.

### Option C — Via GitHub
1. Push this folder to a GitHub repo
2. Go to [vercel.com](https://vercel.com) → Import Project → select the repo
3. Vercel auto-detects static site → deploy
